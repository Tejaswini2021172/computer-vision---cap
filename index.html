Link Scanner

Verify suspicious URLs for phishing indicators and fraud campaigns

How URL Scanning Works

The system performs a structural check on the domain and path, assessing:

  • Typosquatting & Lookalikes

    Scans for character substitutions (like 'rn' for 'm') and brand names mixed with generic words.

  • TLD Domain Risk

    Assesses the safety reputation of the top-level domain extensions (.xyz, .top, .info vs .com).

  • Protocol Safety

    Checks if the link relies on insecure HTTP protocols which lack data encryption.

Groq API Settings

This application processes image uploads and writes custom emails locally in your browser using Groq Llama 4 Scout vision model. A Groq console API key is required to perform analysis.

How to get an API Key?

Go to Groq Console, sign in with your account, and click Create API Key.

Your API key is stored safely on your machine in `localStorage`. It is never uploaded to any server.
